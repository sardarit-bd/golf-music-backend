# 📚 Gulf Coast Music API - Endpoint Documentation

This document provides a comprehensive reference of all API endpoints available on the Gulf Coast Music backend service.

---

## 🌐 Base URL & Conventions
- **Development**: `http://localhost:5000`
- **Production**: Configured via `CLIENT_URL` / domain (e.g. `https://api.gulfcoastmusic.live`)
- **Authentication**: JWT Bearer token sent in `Authorization` header:
  ```http
  Authorization: Bearer <your_jwt_token>
  ```
- **Standard Response Format**:
  ```json
  {
    "success": true,
    "message": "Operation successful",
    "data": { ... }
  }
  ```
- **Standard Error Response Format**:
  ```json
  {
    "success": false,
    "message": "Error description",
    "errors": [
      {
        "field": "email",
        "message": "Please enter a valid email"
      }
    ]
  }
  ```

### Detailed Endpoint Specifications

- **Possible Error Responses**: None

---

#### `POST` /api/stripe/webhook

- **Authentication**: Stripe Webhook Signature Verification
- **Required Role / Permission**: Stripe Service
- **Controller / Function**: `handleStripeWebhook` (in `src/controllers/controller.stripeWebhook.js`)
- **Request Parameters**: None
- **Query Parameters**: None
- **Required Headers**:
  - `stripe-signature`: Cryptographic HMAC SHA256 signature generated by Stripe
  - `Content-Type: application/json` (parsed as `express.raw` in `server.js` prior to JSON middleware)
- **Request Body**: Raw JSON binary payload from Stripe Webhook events
- **Expected Success Response** (`200 OK`):
```json
{
  "received": true
}
```
- **Possible Error Responses**:
  - `400 Bad Request`: `Webhook Error: No signature provided` or signature verification failed
  - `500 Server Error`: `Webhook handler failed: <error_message>`
- **Related Model / Database Collection**: `User`, `Order`, `MarketItem`
- **Important Notes**: Mounted directly in `src/server.js` before `express.json()` middleware using `express.raw({ type: "application/json" })`. Processes `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.payment_succeeded`, `invoice.payment_failed`, and `account.updated`.

## 2. Authentication (`/api/auth`)

| Method | Endpoint | Access | Description |
|---|---|---|---|
| `POST` | `/api/auth/register` | Public | Register new user account (`artist`, `venue`, `journalist`, `photographer`, `studio`, `fan`) |
| `POST` | `/api/auth/login` | Public | User authentication returning JWT token & profile |
| `POST` | `/api/auth/forgot-password` | Public | Initiates password reset flow and emails 15-minute token |
| `PUT` | `/api/auth/reset-password/:token` | Public | Sets new password using verification token |
| `GET` | `/api/auth/me` | Protected | Returns authenticated user details and active subscription |
| `PUT` | `/api/auth/profile` | Protected | Updates basic user profile (state, city, genre) |
| `GET` | `/api/auth/by-location` | Protected | Fetches users filtered by state, city, and userType |

### Detailed Endpoint Specifications

- **Authentication**: Public

- **Controller / Function**: `register` (in `src/controllers/controllers.auth.js`)

- **Query Parameters**: None
- **Required Headers**: `Content-Type: application/json`

```json
  "userType": "artist",
  "state": "Louisiana",

  "genre": "jazz"

```
- **Expected Success Response** (`201 Created`):
```json
{
  "success": true,
  "message": "User registered successfully",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
```

#### `POST` /api/auth/forgot-password

- **Authentication**: Public
- **Required Role / Permission**: None
- **Controller / Function**: `forgotPassword` (in `src/controllers/controllers.auth.js`)
- **Request Parameters**: None
- **Query Parameters**: None
- **Required Headers**: `Content-Type: application/json`
- **Request Body**:
```json
{
  "email": "johndoe@example.com"
}
```
- **Expected Success Response** (`200 OK`):
```json
{
  "success": true,
  "message": "Password reset email sent"
}
```
- **Possible Error Responses**:
  - `400 Bad Request`: `Please provide an email address`
  - `404 Not Found`: `There is no user with that email`
  - `500 Server Error`: `Email could not be sent` (resets token and expiration on failure)
- **Related Model / Database Collection**: `User`
- **Important Notes**: Generates a 20-byte random hex token, stores its SHA-256 hash in `resetPasswordToken` with a 15-minute expiration (`Date.now() + 15 * 60 * 1000`), and dispatches email via Nodemailer. Uses `process.env.FRONTEND_URL` to construct the reset link.

- **Request Parameters**:

- **Query Parameters**: None

- **Possible Error Responses**:
  - `400 Bad Request`: Missing or invalid password

- **Important Notes**: Re-hashes the incoming token with SHA-256, matches against `resetPasswordToken`, checks `resetPasswordExpire > Date.now()`, clears the reset fields, updates password through pre-save bcrypt hook, and logs user in directly with a new JWT.
